# ❌ Tic-Tac-Toe ⭕

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://niainakevinDev.github.io/tictactoe/)

## 📖 Description

Tic-Tac-Toe à 2 joueurs avec interface moderne et gestion des scores.

## 🎮 Fonctionnalités
- 2 joueurs sur le même écran
- Tour par tour automatique
- Détection de victoire/match nul
- Animation de victoire
- Annulation des coups (Undo)
- Score en direct
- Responsive

## 🛠️ Technologies
- HTML / CSS / JavaScript Vanilla
